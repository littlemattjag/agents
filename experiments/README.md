# Experiments

This is my personal sandbox for working through the course. Nothing here needs to
match the original lesson code — the point is to break things, rewrite things,
and see what happens.

## How I'm using this

- Each lesson gets a subfolder here once I start experimenting with it
  (e.g. `experiments/1_foundations/`).
- `notes/` holds my own write-ups per section: what the concept is, what I predicted
  before running the original code, and what actually happened.
- Course updates land on `main` via `git pull upstream main`. To bring them into
  this branch: `git checkout experiments && git merge main`.
